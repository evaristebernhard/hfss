# First parameter checks

These S4P files were solved with the same single-magic-tee v1 geometry and
wave-port normalization as the baseline. Only one design parameter was changed
per case:

| file | changed parameter |
|---|---|
| `g2_4p30.s4p` | `g2 = 4.30 mm` |
| `g2_5p50.s4p` | `g2 = 5.50 mm` |
| `l2_8p00.s4p` | `L2 = 8.00 mm` |
| `w_4p00.s4p` | `w = 4.00 mm` |

They are exploratory full-wave checks, not an optimization result. The E-arm
and tee junction remain the dominant unoptimized features in this simplified
model.
