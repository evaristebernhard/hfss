# v6 四路两级级联仿真

日期：2026-09-22

## 模型

使用三个相同的 v6 阶梯柱 Magic-T 四端口 S 参数组成二叉树：

```text
IN1/IN2 -> MT-A H端口 -- WR90 A --┐
                                  ├-> MT-C H端口 -> OUT
IN3/IN4 -> MT-B H端口 -- WR90 B --┘
```

MT-A、MT-B、MT-C 的 E/差端口均接理想匹配负载。四个输入等幅同相激励。
单胞采用下段半径 2.0 mm、上段半径 1.0 mm 的当前最佳平衡种子。

该模型是完整多端口 S 参数互联，会计入三个单胞之间的多次反射；它不是简单把
单胞效率平方。模型尚不包含两个连接处的三维装配细节、有限电导和场强。

## 等长连接扫描

在 0--30 mm 范围粗扫、4.0--5.5 mm 范围细扫后，最佳等长 WR90 连接为：

\[
L_A=L_B=4.66\ \text{mm}.
\]

此时 9.0--11.5 GHz 的结果为：

| 指标 | 最差 | 最好 | 平均 |
| --- | ---: | ---: | ---: |
| 四路到输出效率 | 36.84% | 约 100% | 72.60% |
| 输入反射功率占比 | 0.0001% | 63.16% | 27.40% |
| E 端口总功率占比 | 0.00004% | 0.00067% | 0.00021% |
| 有源回波损耗 | 1.99 dB | 56.79 dB | 8.75 dB |
| 匹配条件下输入隔离 | 7.38 dB | 18.36 dB | 10.79 dB |

最差效率出现在 9.7 GHz。总输入 30 kW 时，线性 S 参数换算得到：

- 最差输出约 11.05 kW；
- 最大反射约 18.95 kW；
- 差端口最大总功率约 0.20 W。

高效率只出现在三个窄区间：约 9.20--9.275、10.20--10.325 和
11.175--11.375 GHz。级联产生了多次反射形成的三个窄峰，并没有得到连续宽带。

## 支路长度误差

在 10.25 GHz：

| 两支路长度差 | 输出效率 | 输出路径相位展宽 |
| ---: | ---: | ---: |
| 0 mm | 99.99% | 0.13 deg |
| 0.5 mm | 99.66% | 约 5.0 deg |
| 1.0 mm | 98.67% | 约 9.9 deg |

等长连接对中心频点很有效，但无法改善 9.7 GHz 的结构性反射谷。

## 判断

级联拓扑和端口相位关系是正确的：幅度不平衡小于 0.03 dB，等长时路径相位差
小于 0.31 deg，差端口功率也很低。当前主要问题仍是单胞的宽带有源匹配和输入
隔离，而不是二叉树相位接反。

因此可以继续建立完整三维级联模型，但不应把中心频点接近 100% 的结果解释为
达到 95% 宽带效率或 22 dB 指标。

## 完整 3D HFSS 验证

随后建立了三个实体单胞、两段 4.66 mm WR90 连接段和八个外部端口组成的完整
PEC 空腔模型。模型在 HFSS 2025.2 Student 中完成自适应求解和 51 点插值扫频，
没有出现网格上限、端口模式或几何连通错误。

完整 3D 结果为：

| 指标 | 最差 | 最好 | 平均 |
| --- | ---: | ---: | ---: |
| 四路到输出效率 | 36.36% | 99.98% | 72.29% |
| 输入反射功率占比 | 0.021% | 63.64% | 27.71% |
| 有源回波损耗 | 1.94 dB | 35.64 dB | 8.47 dB |
| 匹配条件下输入隔离 | 7.27 dB | 17.96 dB | 10.71 dB |
| 输出路径幅度展宽 | 0.014 dB | 0.056 dB | 0.036 dB |
| 输出路径相位展宽 | 0.054 deg | 0.580 deg | 0.243 deg |

30 kW 总输入的线性换算结果为最差输出 10.91 kW、最大反射 19.09 kW。
效率超过 95% 的离散频段约为 9.20--9.25、10.20--10.30 和
11.20--11.40 GHz；22 dB 有源回波损耗只在少数离散频点达到，输入隔离全带
均未达到 22 dB。

完整 3D 与 S 参数网络级联的输出效率逐频 RMS 差值为 0.55 个百分点，最大偏差
约 -0.90/+1.59 个百分点。这说明网络连接方程、4.66 mm 参考长度和三维装配的
端口极性相互一致，先前的宽带失败结论不是级联算法造成的。
