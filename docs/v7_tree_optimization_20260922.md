# v7 四路级联优化与完整 3D 验证

日期：2026-09-22

## 结论

本轮优化有效，但仍未达到指标。相对于 v6，完整 3D 四路模型的全带最差输出
效率由 36.36% 提高到 50.17%，平均效率由 72.29% 提高到 78.34%。代价是
匹配和隔离仍然很差：最差有源回波损耗只有 2.95 dB，最差输入隔离只有
6.94 dB，远低于 22 dB。

因此，当前结果适合作为下一轮架构优化的种子，不应作为满足 22 dB、95% 效率
或功率容量要求的最终设计。

## 优化路径

先对单个 Magic-T 的阶梯柱做局部参数扫描，再用单胞 S4P 组成完整多端口网络，
联合枚举一级单胞、二级单胞和两段等长 WR90 连接。网络模型保留各级之间的多次
反射。最后把网络最优点重建为三个实体单胞的八端口完整 HFSS 模型进行验证。

筛选得到的同构最优结构为：

| 参数 | 数值 |
| --- | ---: |
| 阶梯柱下段半径 | 1.40 mm |
| 阶梯柱下段高度 | 6.20 mm |
| 阶梯柱上段半径 | 0.90 mm |
| 阶梯柱总高度 | 16.25 mm |
| 两条级间 WR90 长度 | 1.38 mm |

单胞的相干 H/和端输出效率为 78.01%--93.97%，平均 86.99%；相干 E/差端
输出效率为 70.38%--83.40%，平均 77.46%。单胞仍非宽带良好匹配，因此两级
级联后会形成三个高效率窄峰及两个明显反射谷。

## 网络优化与完整 3D 对照

网络优化在 10 个已有单胞候选的 100 种一级/二级组合上扫描连接长度，随后在
最佳区域细化到 1.38 mm。结果如下：

| 指标 | S 参数网络预测 | 完整 3D HFSS |
| --- | ---: | ---: |
| 四路输出效率最差 | 51.84% | 50.17% |
| 四路输出效率平均 | 79.30% | 78.34% |
| 四路输出效率最好 | 99.99% | 99.97% |
| 最差有源回波损耗 | 3.14 dB | 2.95 dB |
| 最差匹配输入隔离 | 7.15 dB | 6.94 dB |

完整 3D 与网络预测的逐频输出效率 RMS 差值为 1.22 个百分点，偏差范围为
-2.29 到 +0.40 个百分点。说明网络模型足以用于这一阶段的快速筛选，同时也
说明宽带失败不是级联脚本的连接或端口极性错误造成的。

## 相对 v6 的改善

| 完整 3D 指标 | v6 | v7 | 变化 |
| --- | ---: | ---: | ---: |
| 最差输出效率 | 36.36% | 50.17% | +13.81 个百分点 |
| 平均输出效率 | 72.29% | 78.34% | +6.05 个百分点 |
| 最好输出效率 | 99.98% | 99.97% | 基本不变 |
| 最差有源回波损耗 | 1.94 dB | 2.95 dB | +1.01 dB |
| 最差输入隔离 | 7.27 dB | 6.94 dB | -0.33 dB |

v7 的完整 3D 最差点位于 9.80 GHz。四路总输入按 30 kW 线性缩放时，输出为
15.05--29.99 kW，最大反射约 14.93 kW；按 1 kW 输入缩放时，输出为
501.7--999.7 W。这只是 PEC 小信号 S 参数的功率换算，不代表已经验证击穿、
热容量或连续波承载能力。

在 51 点离散扫频上，效率不低于 95% 的频段仅为 9.25--9.35、
10.30--10.40 和 11.30--11.50 GHz。有源回波损耗达到 22 dB 的只有少数离散
频点，输入隔离在全带内没有达到 22 dB。

## 一级与二级采用不同单胞的评估

混合级联并未给出同时显著提高效率和隔离的解。效率最优仍是三级使用同一个
1.4/6.2 mm 阶梯柱单胞。若改用 v6 单胞作为一级、1.6/6.2 mm 单胞作为二级，
网络模型可把最差隔离从约 7.14 dB 提高到 8.24 dB，但最差效率降到 43.68%，
最差有源回损也降到 2.48 dB。这个折中离 22 dB 仍很远，暂不值得再做耗时的
完整 3D 求解。

## 下一步建议

继续只扫阶梯柱半径和高度，预计只能移动当前的窄带谐振峰谷。下一轮应引入独立
的宽带匹配自由度，例如在每个 H/和端附近增加可控的多节阻抗变换，或在两级之间
加入针对偶模输入阻抗综合的匹配结构。优化目标应直接使用四路树的最差有源回损、
最差效率和输入隔离，而不是只优化单胞某一个中心频点。

在宽带小信号指标接近目标后，才有必要切换有限电导、保存场并继续验证峰值电场、
击穿裕量、导体损耗和连续波热设计。
